# FinanceBook Web 2.2.1 — Credit limit / debt fix

## Основна поправка
При кредитна карта полето `balance` вече означава **свободен / наличен кредит**, а не дълг.

Формула:
`дълг по карта = кредитен лимит - свободен лимит`

Пример:
- лимит: 2556 €
- свободен лимит: 56 €
- дълг: 2500 €

## Задължения
- „Дълг по кредитни карти“ показва използваната част от лимита.
- Добавено е „Общо задължения“ = останали кредити + дълг по кредитни карти.
- Картата показва лимит, свободен лимит, минимална вноска, лихва и използван процент.
- Погасяване на карта увеличава свободния лимит и намалява дълга.

## Синхронизация
- Firestore schemaVersion е 3.
- Добавено е `creditBalanceMode: available`.
- Legacy Android schema v2, където балансът е бил дълг, се преобразува автоматично при Web import.
- Credit cards не участват като кеш/актив в нетната наличност.
